## 開発方針：RE_Kenshi版に特化

以降はRE_Kenshiを前提に開発します。先端に追従する煙と、吐く時間だけ発生する呼気を正式な対象とし、通常版向けの静止煙は開発対象から外します。

導入は `420_Smoking`（家具・道具・動作）と `420_Smoking_RE`（煙）の2つを使用し、この順で有効にします。RE_Kenshiが必要です。既存のMOD名・アイテムIDは維持します。`420_QA` は開発用です。

確認環境はKenshi 1.0.65 / RE_Kenshi 0.3.5。導入の詳細は `src/re_smoke/README.md` を参照してください。

## 最新の確認状況（2026-09-15）

通常版の静止煙はユーザーの実機確認で紙のように見えるため不採用とし、表示モデルから除去しました。通常版は煙なし、動く先端煙と呼気はRE_Kenshi拡張で対応します。詳細は `qa/vanilla_smoke_feasibility_2026-09-15.md`。

## 作成したもの

- チラム、ジョイント、麻紙、道具置き付き喫煙席の独自モデルとテクスチャ。
- 人間男性用のチラム・ジョイント喫煙アニメーション（各12秒）。吸う2秒、姿勢を3秒保持、吐く3秒に加え、道具を上げる動作と待機を含む。
- 口から吐く煙と先端の少量の常時煙のBlenderプレビュー。
- RE_Kenshi用の煙MOD `420_Smoking_RE` を作成。口の煙を8–11秒に限定し、先端から少量の煙を発生させる専用DLLをビルド・導入済み。2026-09-15、実ゲームの男性・チラムで前向きの呼気と先端煙を確認。ジョイントの実機表示、加速・中断動作は未検証。詳細は `qa/checkpoint_2026-09-15.md`。
- 通常MODは煙なし。静止煙の試作は実機で不自然と判定され、除去済み。口の煙の同期はRE_Kenshi拡張で対応。
- 麻 → 紙、麻＋紙 → ジョイントの製作データ。
- 紙とジョイントを製作リストから選ぶ共通ワークベンチと2種類の喫煙席。設置済みの旧製作台も両方に対応。
- 紙専用・ジョイント専用収納箱。標準のハシシ収納箱を複製し、それぞれ収納対象を変更。
- 喫煙席は対応アイテム1個をセットするギミック。チラム席はハシシ、ジョイント席はジョイント。継続補充なしで吸う方針（1個上限への変更後の実機確認は未完了）。
- 既存セーブを使わず検証するための `420_QA` 新規開始条件。

## 仮の検証設定

設備は所有する建物の屋内設置を基本とします。屋外対応は設備ごとに検証して決めます。初期のゲーム検証用ビルドでは屋外も一時的に許可していましたが、生成ソースは屋内を基本とする設定に変更しています。

紙1個に麻1個、ジョイント1個に麻1個と紙1個。設備の生産倍率は検証用で、ゲームバランスの確定値ではありません。

喫煙席は、生産機能に消費材料を設定し、出力アイテムを空にした実験です。材料が減ること、材料切れで停止することはゲーム内で確認が必要です。データ生成成功は動作成功を意味しません。

道具はFCSの `special tool` を使って表示する試作です。Blenderプレビューの追従成功はゲーム内の追従保証ではありません。
