## 最新の確認状況（2026-09-15）

ユーザーから、煙の増量後の表示に加え、直前に列挙した残りの確認項目も「確認済み」と報告を受けました。ビーズクッションの姿勢・沈み込み・足の接地、建築時の回転、製作速度・収納・材料の扱い、ジョイント・女性・他種族の表示、倍速・一時停止・中断・ロード時の挙動が対象です。これはユーザーによる確認報告であり、個別の測定値や再現手順の追加記録はありません。以下および過去のQA記録の「未確認」は各作業時点の履歴です。詳細は `qa/user_confirmation_2026-09-15.md`。

仕様の正本は `Kenshi_喫煙MOD_仕様書.md`。バフ・デバフは対象外です。

## 作成したもの

- チラム、ジョイント、麻紙、道具置き付き喫煙席の独自モデルとテクスチャ。
- 人間男性用のチラム・ジョイント喫煙アニメーション（各12秒）。吸う2秒、姿勢を3秒保持、吐く3秒に加え、道具を上げる動作と待機を含む。
- 口から吐く煙と先端の少量の常時煙のBlenderプレビュー。
- RE_Kenshi用の任意追加MOD `420_Smoking_RE` を作成。口の煙を8–11秒に限定し、先端から少量の煙を発生させる専用DLLをビルド・導入済み。2026-09-15、実ゲームの男性・チラムで前向きの呼気と先端煙を確認。ジョイントの実機表示、加速・中断動作は未検証。詳細は `qa/checkpoint_2026-09-15.md`。
- 通常MOD向けに先端の煙の形を付けた表示専用モデルを組み込み済み（試作）。静止した煙メッシュで、流れる粒子ではない。ゲーム画面での見た目は未検証。口の煙の同期は未実装。
- 麻 → 紙、麻＋紙 → ジョイントの製作データ。
- 紙とジョイントを製作リストから選ぶ共通ワークベンチと2種類の喫煙席。設置済みの旧製作台も両方に対応。
- 紙専用・ジョイント専用収納箱。標準のハシシ収納箱を複製し、それぞれ収納対象を変更。
- 喫煙席は対応アイテム1個をセットするギミック。チラム席はハシシ、ジョイント席はジョイント。継続補充なしで吸う方針（1個上限への変更後の実機確認は未完了）。
- 既存セーブを使わず検証するための `420_QA` 新規開始条件。

## 仮の検証設定

設備は所有する建物の屋内設置を基本とします。屋外対応は設備ごとに検証して決めます。初期のゲーム検証用ビルドでは屋外も一時的に許可していましたが、生成ソースは屋内を基本とする設定に変更しています。

紙1個に麻1個、ジョイント1個に麻1個と紙1個。設備の生産倍率は検証用で、ゲームバランスの確定値ではありません。

喫煙席は、生産機能に消費材料を設定し、出力アイテムを空にした実験です。材料が減ること、材料切れで停止することはゲーム内で確認が必要です。データ生成成功は動作成功を意味しません。

道具はFCSの `special tool` を使って表示する試作です。Blenderプレビューの追従成功はゲーム内の追従保証ではありません。

## 完成までに必要な確認

- [ ] 紙とジョイントが設定数量で製作される。
- [ ] 喫煙席を設置でき、指定したキャラクターが利用できる。
- [ ] 喫煙中に対応する材料が消費される。
- [ ] 材料切れ・移動命令・戦闘で意図せず継続しない。
- [ ] ゲーム内でも道具が手に自然に追従する。
- [ ] 指や顔との重なりを調整する。
- [ ] 女性・他の対応種族を検証する。
- [ ] セーブ・ロードで製作・在庫・家具利用が維持される。
- [ ] 検証用設定を外し、説明文と導入手順を確定する。
