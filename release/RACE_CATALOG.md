## Existing animation patches

The local Project -Ultimate Anim Patch- contains 737 race records. The original race mods are not all installed, so this count does not represent supported coverage. Existing registrations are used to assess duplicate or unnecessary additions.

## Scope

- Separate patch folders and distribution archive.
- Minimal animation-reference additions, preserving original stats, appearance, names, translations, and existing animation references.
- Individual patches for installed original mods; no bulk references to absent races.
- No third-party meshes or animations bundled.
- Validation is limited to locally installed original mods. Users check other environments.
- A comprehensive survey of all Workshop race mods has not been completed.
