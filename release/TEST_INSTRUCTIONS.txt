420 Smoking — Distribution Test Bundle

CORE: 420_Core.zip
Extract and copy mods/420_Smoking and mods/420_Smoking_RE into Kenshi/mods.
Install RE_Kenshi separately. Enable 420_Smoking, then 420_Smoking_RE.
Core 0.1.0-rc3 includes the chair-facing correction and an immediate-standing
mitigation. Repeated seating and position checks for the latter remain pending.
The renderer-error cleanup and tip-smoke visibility fixes are retained.

OPTIONAL: 420_Patches.zip
Copy mods/420_Races into Kenshi/mods and enable it after your race mods,
420_Smoking, and 420_Smoking_RE. Disable old 420_Smoking_Patch_* entries.
One folder covers 59 configured humanoid race IDs. The plugin explicitly
skips absent races; the MOD contains zero race records. Races.json can be
extended without rebuilding the DLL. Read its README before editing.
Races 0.1.0-rc3 includes the preload-timing fix. Startup tests confirmed zero
registrations without supported race mods and two with the tested 2B mod.
These tests do not establish visual fitting for every supported race.
