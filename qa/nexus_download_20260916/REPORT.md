# Nexusダウンロード版チェック（2026-09-16）

対象: 420 Core 0.1.0-rc1 / 420 Races 0.1.0-rc2、ユーザー指定のDesktop上のZIP。

## 結果

配布物の整合性・データ・模擬実行テストは合格。ゲーム内動作は今回未確認で、動作保証とは区別する。

- 両ZIPのCRC、パス、重複名、SHA256マニフェストを確認。Core 32ファイル、Races 13ファイルが一致（各SHA256.json自身を除く）。
- 配布ランタイム全ファイルが現在のbuildとバイト一致。C++/ヘッダーもローカルのテスト対象ソースと一致。
- MODの参照先レコード・アセットに欠落なし。DLLは両方x64、プラグイン設定の参照先も存在。
- 研究Lv3、本3＋麻3、基準4時間、7設備・2レシピの解放を確認。
- 共通製作台、旧製作台対応、材料分離、専用収納のデータ検証に合格。
- バニラ人型31種族、男女アニメ、既存種族への追加変更の検証に合格。
- Racesはアニメ定義6件、種族レコード0件。59種族のID・プロファイルと元MODのハッシュ照合に合格。
- 登録コードの再コンパイル・模擬DBテストに合格（対象なし、部分導入、全導入、重複、未対応種族、欠落アニメ、型違い、例外、hook失敗、不正設定、追加種族）。実ゲームのhook実行ではない。
- 煙の例外処理5ケースに合格。描画処理と両方の後始末が失敗した場合、例外は外へ漏れないが煙が消えることは保証されない。
- BoostのJSONパーサにC4715コンパイラ警告あり。今回のテストは正常終了。
