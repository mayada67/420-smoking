# Nexus公開前の整合性監査（2026-09-15）

## 結論

参照切れや必須ファイル欠落は検出されなかった。ただし公開用の名称・説明は未整備。対応キャラクター範囲と通常プレイでの設備解放は、公開説明を確定する前に確認が必要。
この監査は実際のMODバイナリ、ローカルのゲーム基盤データ、配布候補ファイルを読み取ったもの。ゲーム起動・Nexusへのアップロード・配布ファイルの変更は行っていない。

## 公開前に対応する事項

### 1. ゲーム内名称と説明

| 現在 | 公開用の候補 |
| --- | --- |
| 420 Hemp Paper [ALPHA] | 420 Hemp Paper |
| 420 Joint [ALPHA] | 420 Joint |
| 420 Smoking Workbench [ALPHA] | 420 Smoking Workbench |
| 420 Smoking Workbench (Legacy) [ALPHA] | 420 Smoking Workbench (Legacy) |
| 420 Chillum Seat [ALPHA] | 420 Chillum Seat |
| 420 Joint Seat [ALPHA] | 420 Joint Seat |
| 420 Worn Beanbag: Hashish | 420 Worn Beanbag: Chillum |
| 420 Worn Beanbag: Joint | 変更不要 |
| 420 Storage: Paper / Joints | 変更不要 |
| 建築カテゴリ 420 SMOKING TEST | 420 SMOKING |
| 研究 420 Smoking Prototype | 420 Smoking |

BeanbagのHashishは材料名で、通常席のChillumは器具名。対応する席同士で命名基準を揃える候補を示した。収納カテゴリがSTORAGEなのは用途上自然であり、不整合とは扱わない。

研究説明の「Prototype test facilities; not a completed mod.」、基盤MODヘッダーの「UNFINISHED ALPHA」「NOT VERIFIED」、煙MODヘッダーの「EXPERIMENTAL」を現在の状態に合わせて更新する。内部表示用アイテムの[STATIC WISP]、アニメーションレコードの[ALPHA male only]も古い。

名称変更は生成ソースと両MODに反映する必要がある。JSONだけ変更してもゲームには反映されない。公開名の候補は「420 Smoking — RE_Kenshi」。作者欄は現在「420 project」で、公開時の作者名として適切かを決める。

### 2. 対応キャラクター範囲

基盤MODの種族変更はGreenlander（17-gamedata.quack）のみ。通常・リクライニングともmale animationだけ設定され、female animationは空。
ユーザーから女性・他種族について確認済みとの報告を受けているが、具体的な種族・性別・他MOD構成の記録はない。これを未動作と断定はしない。ただし公開ページで全種族・男女対応と記載する根拠としては不足する。配布候補2MODとRE_Kenshiだけの環境で対象を特定し、対応範囲を記載する。

### 3. 通常プレイでの研究・建築

研究レコードは存在し、通常作業台・4席・2収納と2レシピへの参照が成立している。旧作業台は既存設置物向けに保持され、新規解放対象から外れている。
研究はlevel=0、time=0、費用0、前提研究なし。420_QAの開始条件は研究を解放済みにするため、QA開始だけでは通常の解放経路を検証できない。通常開始・既存セーブで研究や設備が利用できることを確認し、実際の解放方法を導入説明に記載する。

## 合格した静的チェック

- 基盤33レコード、煙MOD3レコードをバイナリから読み戻した。
- レコード参照と配置インスタンス参照に欠落なし。
- ファイル参照20種類すべて存在。ゲーム本体参照もローカル環境で存在。
- MODフォルダ名と.mod名が一致。煙MODは420_Smoking.modへの依存を宣言。
- RE_Kenshi.jsonのSmokingSmoke.dllが存在。配布候補ソースと正本ソースが一致。
- 通常席・ビーズクッションのチラム/ジョイント4経路について、設備→機能→アニメーション→道具参照が成立。アニメーション名がskeleton内およびDLLのソースと一致。
- records.jsonとバイナリは浮動小数点の保存精度差を除いて一致。
- 導入済みゲームとの相違はrecords.json、README、同梱ソースのみ。実行用MOD、DLL、アセットに相違なし。
- 現在の有効順は420_Smoking、420_QA、420_Smoking_RE。RE版は有効。

## ファイル名・配布構成

`420_Smoking/420_Smoking.mod`、`420_Smoking_RE/420_Smoking_RE.mod`、`SmokingSmoke.dll`は整合しており改名不要。MOD名はレコードID・依存宣言・アセット参照にも使われるので、公開タイトルに合わせて変更する必要はない。`_male`は制作ファイルの名前であり、それだけで対応範囲を定義しない。

配布対象は上記2MODを基本とする。420_QA、Prototype、ツールチェーン、基盤データ、QAバックアップは含めない。
`records.json`は実行不要。assets側の3つのアイコンはitems/icons側と重複し、FCSが参照するのは後者。配布用ステージを作る際に除外できる。
`_lit.mesh`と煙用アトラスはRE側で上書きされるが、基盤MODが参照している。未参照と見なして単純削除しない。
LICENSEとソースは開発用だからという理由で除外しない。現在はGPL本文とcppが同梱される一方、ビルドスクリプトは同梱されていない。公開ソース一式・ビルド方法・依存先を一緒に用意し、基盤モデルやアニメーションの利用条件も明示する。これは梱包状況の指摘であり、ライセンス適合性の法的判定ではない。

## 残る作業の順序

1. 上記名称・説明を生成ソースから修正し、IDを維持して再生成する。
2. 通常プレイでの設備解放と対応キャラクター範囲を確認する。
3. 実行用2MOD、利用者向け導入・操作説明、ソースとライセンスを公開用に梱包する。
4. その梱包物を展開して最終起動確認する。多数同時使用時の負荷は別途未計測。

監査スクリプト: `tools/audit_release.py`。機械可読の全名称・参照結果: `qa/release_audit.json`。
