# Kenshi 喫煙MOD：仕様照合と次の検証

調査日：2026-09-12。対象はローカルのKenshi 1.0.68と本MODの試作データ。バフ・デバフは対象外。

## 結論

紙・ジョイントの製作は標準の材料入力／製品出力の構成を利用できる。紙専用収納箱も標準箱の収納制限を変更する構成で追加できる。ただし、データの成立とゲーム内動作の成立は別である。

最大の未確認点は喫煙席の「出力なし生産」。標準のBUILDING_FUNCTIONALITYを走査した範囲では、入力があり出力がないfunction=4の例は見つからなかった。製作設備のfunction=10には別のcrafts参照、発電機のfunction=5には別の動作があるため、これらを消費専用生産の証拠にはできない。現在の喫煙席は実験であり、完成仕様として扱わない。

## 標準定義との照合

一次資料はインストール済みゲームの `fcs.def` と、標準4データファイルを統合したローカル参照データ。定義の説明はエンジン内部の全動作を保証しない。

| 項目 | 根拠 | 判断 |
| --- | --- | --- |
| 紙だけを収納 | fcs.def:420、limit inventory | ITEM参照で収納対象を制限する |
| 屋内家具 | fcs.def:489、is interior furniture | プレイヤー設置時の屋内条件。所有権や経路とは別に確認する |
| 傾斜 | fcs.def:494、max slope | 建物ごとの許容角。すべての設備に水平必須と一般化しない |
| 収納倍率 | fcs.def:506、stackable bonus mult | アイテム側のstackableに掛かる。箱の枠数だけでは総容量は決まらない |
| 材料消費 | fcs.def:516、consumes | 第1値は保管上限、第2値100は入力／出力比1:1 |
| 製品出力 | fcs.def:519、produces | 非クラフト型生産の製品参照 |
| 作業小物 | fcs.def:521、special tool | 外観用のITEM。装備品としての所持を意味しない |

## 紙収納箱

元データは `55236-rebirth.mod`（Storage: Hashish）。新規レコードは `25-420_Smoking.mod`。

- parts、functionality、全作業ノード、設置条件、収納枠5×5、収納倍率50、建築設定を継承。
- 名前・説明文とlimit inventoryだけを紙用に変更。元のハシシ箱は変更しない。
- 試作研究の建築解禁に追加。標準STORAGEカテゴリを継承。
- 自動搬入、取り出し、紙以外の拒否、セーブ後の在庫保持は未検証。

比較結果は [paper_storage_checks.json](paper_storage_checks.json)。紙のstackableは試作値なので、標準ハシシ箱と総収納個数が同じとは限らない。

## 表示とアニメーションの公開資料

Lo-Fi公式の[Blender対応Modders Pack説明](https://lofigames.com/updated-modders-pack-now-available/)は、UV、スキン付きメッシュと静的メッシュの出力条件、骨格名・骨の変更に関する注意を示す。2016年の旧プラグイン向け資料なので、現在のIO Toolsの設定を直接保証する資料にはしない。

家具MOD作者の[作業用小物の検証報告](https://steamcommunity.com/app/233860/discussions/3/1318835718947606202/)では、武器ではなくITEMとして小物を作り、special toolを使う方法で表示できたと報告されている。現在の方針の参考にはなるが、2017年の報告であり、独自Propボーンの位置・向きや現行版の挙動は別途確認が必要。

[Kenshi Cigarettes作者の説明](https://steamcommunity.com/sharedfiles/filedetails/?id=2259319456)では、タバコ類はベルト枠に入れる装備として説明されている。本MODの材料消費と家具作業の成立を示す例ではない。

[Mod item iconsの当事者による解決報告](https://steamcommunity.com/app/233860/discussions/3/133260909493021484/)は、MOD直下の小文字itemsフォルダーを指摘している。現在のassets内PNGが存在していてもゲーム側の資源検索対象とは限らない。これは赤い×表示の修正候補であり、適用後の表示確認が必要。

## ゲーム操作前の検証条件

テスト開始条件は全33能力100、100万Cats、材料とバックパック、Heft開始を設定済み。これらはバイナリ読み戻し確認までで、実際の新規開始後の配布・出現位置は未確認。

設備検証は所有済み・修理不要の建物で行う。屋内の空き床、衝突、使用位置への経路を確認する。町の近くで屋外建築を試して屋内設備の成否を判断しない。購入可否は対象建物の表示で確認する。

## 最小の確認順序と停止条件

1. 新規テスト開始：資金、能力、装備、材料を確認。足りなければ配布データだけを修正する。
2. 所有建物に紙製作台を1台設置。麻1個を供給し、紙1個が出るか確認。失敗したら喫煙動作の試験へ進まない。
3. 紙収納箱を設置。紙を入れて取り出し、麻・ハシシが入らないか確認。紙製作からの自動搬入も別に確認する。
4. ジョイント製作台へ麻1個＋紙1個を供給。ジョイント1個の生成と両材料の減少を確認。
5. 消費試作を既存の座り動作で確認。無出力で作業が開始しない場合、同じ命令を繰り返さず方式を再検討する。副産物を勝手に完成仕様へ追加しない。
6. 消費が成立してから独自動作と小物表示を確認。空在庫、中断、再開、保存と読込をそれぞれ確認する。

現段階でゲーム内の消費、手への追従、完成判定の合格は報告できない。
